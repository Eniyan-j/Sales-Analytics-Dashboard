#Sales Analytics Dashboard

## Overview

This project is an end-to-end Sales Analytics Dashboard developed using Python, MySQL, Power BI, and DAX. The objective is to analyze sales performance, customer behavior, regional performance, and profitability to support business decision-making.

---

## Tools Used

- Python
- Pandas
- NumPy
- Jupyter Notebook
- MySQL
- Power BI
- DAX

---

## Workflow

1. Data Cleaning using Python
2. Exploratory Data Analysis (EDA)
3. SQL Business Analysis
4. Power BI Dashboard Development
5. DAX Measures
6. Business Insights

---

## Key Business Insights

- Technology generated the highest sales.
- A small number of customers contributed a significant share of revenue.
- Higher discounts were associated with lower profitability.
- The West region generated the highest sales.
- Some products generated high sales but resulted in negative profit.
